SMART ENTERPRISES MOTOR CONTROL — INTERACTIVE FRONTEND DEMO

RUN
1. Extract the ZIP.
2. Open index.html in Chrome or Edge.
3. Use the left navigation or the screen-specific buttons to move through the supplied screens.

FUNCTIONALITY INCLUDED
- Screen-to-screen navigation from the supplied screens.
- Login form demo validation and demo login routing.
- Start/Stop/Fault reset simulated local state.
- Schedule save stores form values locally in the browser.
- Protection toggles and numeric stepper controls.
- Settings save/review/apply confirmation flow.
- Browser localStorage used for demo settings.

IMPORTANT
This is a functional frontend prototype. It does not connect to a real motor, PLC, IoT gateway, API, authentication service, or electrical protection relay. Start/Stop, reset, save and apply actions are simulated only. Do not connect to hardware until authenticated backend APIs, authorization, telemetry feedback, interlocks, safety validation, and device integration are implemented and tested.
